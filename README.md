# 上海二手房数据集（可视化用）

COMP7507 Visual Analytics 课程数据集：上海市 16 个区、167 个板块、2,242 个小区的二手房挂牌数据，
按 **「房源明细 → 小区聚合 → 行政区（年鉴）」** 三层组织，另附一张整合大宽表。

## 文件

| 文件 | 粒度 | 行 × 列 | 主键 | 说明 |
| --- | --- | --- | --- | --- |
| [`01_房源明细_houses.csv`](01_房源明细_houses.csv) | 单条挂牌房源 | 5,850 × 29 | `房源ID` | 价格、面积、户型、楼层、装修、挂牌日期、标签、中介 |
| [`02_小区总表_community.csv`](02_小区总表_community.csv) | 小区 | 2,242 × 49 | `区`+`小区` | 小区聚合中位数、地铁可达性、GCJ02/WGS84 坐标、500m POI、生活便利度 |
| [`03_区表_年鉴口径_district.csv`](03_区表_年鉴口径_district.csv) | 行政区 | 16 × 41 | `区` | 《上海统计年鉴2025》口径：人口、财政、房屋、绿地、教育医疗、经济 |
| [`04_整合大宽表_all_in_one.csv`](04_整合大宽表_all_in_one.csv) | 单条挂牌房源（含广播字段） | 5,850 × 115 | `房源ID` | 上面三张表的全部字段合成一张，**无需建连接**；但 86 列是广播列，聚合规则见下方 |

## 表间关系

```
01 房源明细 (5,850) ──区+小区──▶ 02 小区总表 (2,242) ──区──▶ 03 区表 (16)
                                        │
                              04 = 01 ⊕ 02 ⊕ 03（按 区+小区 / 区 广播）
```

- Tableau 建议用**关系（Relationship）**：`01` ⟷ `02` 按 `区`+`小区`；`01`/`02` ⟷ `03` 按 `区`
- 🚩 不要按行号连接（01 与 02 行序不同）
- 🚩 **不要 SUM 广播列**：04 表里小区级/区级指标在每个明细行都重复存了一份。
  实测 `SUM(年末常住人口_万人)` 会比真实值大 **580 倍**、`SUM(挂牌数)` 大 6.5 倍。
  这些字段请用 `MIN` / `ATTR`（中位数类用 `MEDIAN`）。
  区级切面图请直接用 `03` 表（16 行，一行一区），不必写 LOD。

## 数据来源

- 房源挂牌数据：房天下上海二手房（`sh.esf.fang.com`），抓取于 2025-12，挂牌日期 2025-09-07 ~ 2025-12-07
- 区级统计：上海市统计局《上海统计年鉴2025》（2024 年数据）· https://tjj.sh.gov.cn/tjnj/tjnj2025.htm

## 已知数据问题

完整清单见 [`字段说明.md`](字段说明.md)，重点几条：

- ⏳ **待补充**：`便利店_500米`、`餐饮_500米`、`商场_500米`、`超市_500米`、`医院_500米`、`学校_500米`、`生活便利度指数` 这 7 个指标目前只有 **584 / 2,242** 个小区有值，其余为空，正在补充中；在此之前不要用它们算覆盖率，也不要把空值当 0
- `议价空间_百分比` 有 1,114 个负值，属正常业务含义（挂牌价高于评估价），不是脏数据
- `历史成交笔数` 被截断在 4（5,394 行为 4），应理解为「4 笔及以上」，不可当连续变量
- 1,939 / 2,242 个小区挂牌数 < 5，中位数不稳定，建议默认用 `样本量是否充足 == True` 过滤
- 金山区的「最近地铁站」口径特殊（实际有市域铁路金山卫站），可达性分析需单独处理
