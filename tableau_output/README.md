# D3 小区加权推荐 · Tableau 交付

主文件：[D3_加权推荐_v2.twbx](D3_加权推荐_v2.twbx)。这是一个自包含的 Tableau 工作簿包，内嵌 Hyper 数据提取，不需要再连接外部 CSV。v2 将仪表板设置为唯一可见入口，并隐藏地图、排名和明细三个底层工作表，避免网页端默认打开单张地图。

## 数据范围

- `CommunityScores`：1,467 个小区；来自官方发布包的 `tableau_ready/08_D3小区级_打分用.csv`。
- `ListingDetails`：35,569 条房源；来自同一发布包的 `v3/01_房源子集_旧表小区.csv`。
- 未补充、拼接或改写原始数据。两张表仅以 `区 + 小区` 建立 Tableau 逻辑关系。

## 仪表板能力

- 按区筛选；
- 教育、医疗、地铁三项权重参数（默认 33/33/34）；
- 区内 Min-Max 标准化：学校/医院数量越多越好，步行地铁时间越短越好；
- 小区得分地图（颜色为综合分，大小为挂牌数）；
- 推荐排名表；
- 从地图或排名表选择小区后，筛选到房源明细。

## 打开与发布

使用 Tableau Desktop 或 Tableau Public 打开 `.twbx`，进入 `Dashboard 3 · 小区加权推荐`。确认显示效果后，使用 Tableau 的“发布工作簿”功能选择你的 Tableau Cloud/Server 站点和项目。

当前交付只在本地生成文件；它没有使用或保存任何 Tableau 账号凭证，也没有向账号发布内容。

## 可复现构建

在项目根目录运行：

```powershell
uvx --from "cwtwb[examples]" python .\build_d3_tableau.py
```

该脚本拒绝覆盖现有输出，避免意外替换已确认的工作簿。
