# V2 清洗版 · 上海二手房挂牌数据（安居客全量）

> **171,344 条房源 · 13,387 个小区 · 16 个区 · 303 个街道**

本表基于安居客上海二手房挂牌数据（原始 175,135 条 / 47 列），完成**字段补全**与**数据清洗**，
并与上一版的地理坐标、2024 年鉴指标合并。

**适用场景**：区级 / 街道级空间描述、房源属性分析、房价梯度分析。

## 三、本次清洗做了什么

| # | 处理 | 影响 |
|---|---|---|
| 1 | **从原始文件补回 6 个字段** | **户型（居室数/厅堂数/卫生间数）**、产权年限、参考预算、地址、标题、链接 —— 原 V2 完全没有 |
| 2 | **4 个带单位字符串转数值** | `"28445元/㎡"`→28445 · `"50户"`→50 · `"0.4 元/平米/月"`→0.4 · `"30.00%"`→30.0 |
| 3 | **拆分 `楼层位置`** | `"中层(共11层)"` → `楼层层级=中层` + `总层数=11` |
| 4 | **解析 `参考预算`** | `"首付10万，月供1796元"` → `首付_万=10` + `月供_元=1796` |
| 5 | **剔除上海周边** | −1,159 条（南通 / 嘉兴 / 慈溪 / 昆山 / 湖州 / 苏州） |
| 6 | **剔除经纬度缺失与坐标异常** | −68 条 |
| 7 | **去重** | −1,675 条（同小区、同价、同面积、同属性的重复挂牌） |
| 8 | **修正建造年份异常** | 4 条 >2024 的置为缺失 |
| 9 | **新增派生列** | `户型`、`到市中心距离_公里`、`区域`、`房龄段`、`面积段`、`房龄` |

## 六、必须知道的局限

1. **无 500m 配套设施数据**（医院 / 学校 / 便利店 / 餐饮 / 商场 / 超市）
   —— 这是 **V3 的职责**。V2 拿不到，做设施相关性分析必须换 V3。

2. **无地铁步行时间** —— 只有平台的 `近地铁` 布尔标注（是 / 否），**不是精确距离**。

3. **全部是挂牌价，不是成交价** —— 挂牌价通常高于成交价，且含中介话术成分。

4. **26.3% 的坐标只到区县级** —— 小区级地图上会大量重叠。

5. **`小区均价_元每平` 与 `单价_元每平` 高度共线（ρ = 0.967）**
   —— 做相关性分析时**不要同时放入**，否则 `小区均价` 会虚假占据榜首（它本质是单价的小区均值）。

6. **`区域`（中心城区 / 郊区）是派生的二值字段** —— 较粗。
   需要更细的空间分层时，请用 `街道` 或直接用 `经度 / 纬度` / `到市中心距离_公里`。

## 七、生成说明

- **原始文件**：`house_price_raw.csv`（47 列，安居客）
- **关联方式**：与 `v2/01_房源级.csv`（坐标 + 年鉴）按 `区 + 街道 + 小区 + 面积 + 价格` 关联，
  **匹配率 100%**（171,344 / 171,344）
- **坐标基准**：**GCJ-02**
- **房龄基准年**：**2024**（`房龄 = 2024 − 建造年份`）
  > ⚠️ 旧 `final_tables_v2` 用的是 **2025** 基准，两版房龄相差 1 年，跨版本对比时注意。
