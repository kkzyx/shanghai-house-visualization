三个 Dashboard 原型、Tableau 构建指引、5 张预计算表都在仓库里，可直接在线打开。 完整的房源明细数据（171,344 条 / 78 MB）在课程提交的压缩包中，未放进仓库以避免超出 GitHub 的单文件体积限制。

数据可靠性说明
所有数据均可溯源：v2/ 的每一行都能在原始抓取文件 house_price_raw.csv（2024-07-15）中找到对应（实测 100%）； v3/ 是 v2/ 的严格子集（实测逐小区条数 100% 一致）。 48 个字段中 30 个直接来自原始抓取（其中一半仅去掉单位），8 个由已有字段派生，3 个来自地理编码流程，7 个来自公开年鉴。 验证细节见构建指引的 §6 数据验证证据。
